# 在 Cloudflare 上搭个人网盘（R2 + Workers）

单文件、无需服务器。存储用 R2（免费额度：10GB 存储 / 每月 100 万次 A 类操作 / 1000 万次 B 类操作，免流出流量费），
界面和鉴权由一个 Worker 搞定。

## 部署步骤（全程网页操作，不用敲命令）

### 1. 创建 R2 存储桶
- Cloudflare Dashboard → 左侧 **R2 对象存储** → **创建存储桶**
- 名称填 `mypan`（小写，只能用小写字母、数字和连字符），位置选自动 → 创建

### 2. 创建 Worker 并粘贴代码
- 左侧 **Workers 和 Pages** → **创建** → **创建 Worker** → 随便起个名 → **部署**
- 点 **编辑代码**，把 `worker.js` 的全部内容粘贴进去，覆盖原来的 → **保存并部署**

### 3. 绑定 R2 存储桶
- 进这个 Worker → **设置** → **绑定** → **添加绑定**
- 变量名称填 `BUCKET`（必须大写，一字不差）
- 存储桶选刚才建的 `mypan` → 添加

### 4. 设置登录密码
- **设置** → **变量和机密** → **添加** → 类型选**机密**
- 变量名称填 `PASSWORD`，值填你想要的登录密码 → 保存
- 回到代码页再点一次**部署**（让机密生效）

### 5. 绑定你的域名
- **设置** → **域和路由** → **添加自定义域**，填你的域名（如 `pan.你的域名`）
- 域名需要在 Cloudflare 托管 DNS（免费域名一般都支持接入）
- 等 1-2 分钟生效后，打开域名 → 输入密码登录 → 开始用

## 功能
- 📁 文件夹浏览、面包屑导航
- ⬆️ 多文件上传、拖拽上传
- ⬇️ 下载、🗑 删除、📁 新建文件夹
- 🔗 分享：生成带有效期的私密链接（最长 720 小时），不用登录也能下载
- 🔒 全站密码保护，cookie 有效期 30 天

## 注意事项
- 单文件上传建议 100MB 以内（Workers 免费版内存限制，大文件可能失败）
- 分享链接签名和登录都依赖 `PASSWORD`，改密码后旧分享链接自动失效
- 免费版 Worker 每天 10 万次请求，个人用绰绰有余
- 定期去 R2 看一下用量，别超免费额度
